# 视频攻略解析与复核

地下城、深域、活动首领、追忆战场、深渊讨伐战及斗技场共用正式解析器，搜索、头像准备、缓存和解析均由程序完成，不要求 Agent 前处理。身份识别成功不等于完整作业可执行。配置与命令见[深域](guides/abyss.md)、[地下城](guides/dungeon.md)、[活动](guides/story-event.md)、[追忆战场](guides/recollection.md)、[深渊讨伐战](guides/abyss-subjugation.md)、[斗技场](guides/battle-stadium.md)。

## 来源与缓存

`sources.refresh_media: true` 可在视频过度压缩或缓存损坏时重新取得媒体并重新解析，默认关闭。仍按高清、中清、标清顺序和原有下载时间／大小边界执行；新媒体完整解码通过后才替换旧文件，失败保留原缓存。刷新不能保证源视频更高清，也不能放宽身份识别。

- 公共搜索入口为 `strategy_sources.discover_sources()`，正式获取入口为 `strategy_video.acquire_strategies()`；任务可传入 `SourceRules`，提供查询生成、来源拒绝规则、完整作者评论要求和目标缓存字段。规则须有可更新的版本标识；游戏身份、服区、预算与后续画面核验仍由公共流程执行。内置深渊规则复用 `subjugation_guides`，指定链接与搜索结果使用相同元数据格式和拒绝规则。
- `sources.search_queries` 可补充最多20条、每条1～200字的查询，与任务默认查询合并去重。补充词只扩大搜索入口，不能证明队伍、难度或操作适用；查询、规则版本与目标范围均参与缓存隔离。
- 先解析指定链接，调用方确认已有可用候选后不再启动搜索；未取得候选且解析名额仍有余量时，再搜索精确关卡视频并处理评论引用。同类候选优先较新发布时间；深域高努力值搜索也查“关卡名 全 set”，追忆战加强搜索兼查“追忆的战场 AUTO／全制霸参考”和具体层数，扩大元数据核验范围后优先单层与较新候选。失败预算耗尽后仍可搜索，不能因此增加战斗预算。
- 读取视频及分 P 元数据后再分配解析名额。正常深域执行会跳过明确手动、改星、1 押、TP+2 等未支持要求或超过 `max_video_seconds` 的目标分 P；`prepare_only` 可保留媒体供复核。跨属性或已排除的候选不占有效解析名额。
- 单属性合集标题与分 P 可共同证明范围；多属性合集需画面明确目标。标题“1-5图”表示章节范围，不能当成精确关卡 1-5。分 P、表格或画面冲突时拒绝，不以合集标题推断本关适用。
- 追忆战合集标题明确属于单一领域时，可检查仅写“火物1～3”等范围的分 P；多领域合集不能这样关联。“追忆战·霸”只表示玩法，具体单层仍须由画面核验，范围标题不能补写为本关。
- 单一领域与层数范围明确的合集可检查无层数的“参考作业”等总览分 P；总览仍只提供解析候选，明确属于其他层数的分 P 不会补写为本关。
- 下载受大小、时间与完整性限制；媒体传输进程单独受总时限和无进展时限控制，TLS 读取阻塞时也会结束该传输，协作停止会清理子进程。依次尝试高清、中清和标清，在同一总时间边界内为后续码率保留时间；仍须解码、时长及多帧校验。部分下载不发布为有效缓存。
- 媒体按有界 Range 分段下载，逐段核对偏移、响应总长度与实际字节数；服务器忽略 Range 时仅允许首段按完整响应读取。传输中途出现完整响应、范围错位或截断时拒绝发布，不拼接错位数据。
- 公共头像/国服身份自动建立于 `cache/game/avatars/reference/`，与账号观察分开；缺少国服身份时保留未知 ID。媒体和解析报告位于 `cache/game/strategies/media/`、`parsed/`，不提交真实数据。
- 近期候选 ID 可跨搜索刷新与解析器版本保留，但必须重新取得元数据、按当前范围/时长/手动要求过滤并解析。候选缓存不是已核验阵容。
- 直接战斗来源的解析缓存按目标身份、等级、生命上限及范围隔离，截图文件名不同不会强制重解码。每次调用仍须提供新的现场证据，复用时重新绑定该证据；缺少现场证明或目标变化不复用原目标的匹配结果。
- 后续来源批次在元数据及视频名额分配前排除已尝试的来源，让搜索结果中的后续候选进入核验。排除集合参与来源缓存和解析汇总报告的标识，不能重复读取首批截断后的缓存再过滤为空；每批解析数量、总批次和时间上限仍独立生效。
- 浏览器回退搜索优先读取视频卡片标题，播放量和时长不作标题；跨服公会招募广告不用于判定实战服区。服区由来源标题或明确说明核验；追忆战还可同时核对固定位置的编队标题和开战按钮，或难度按钮和首通标签，以确认简体／繁体客户端。与明确来源服区冲突时拒绝。
- 同一分 P 同时包含关卡和练度说明时按 CID 只解码一次。

## 识别边界

| 内容 | 证据要求 |
|---|---|
| 五人身份 | 五名不同角色、至少两帧证据。黑帧、强遮挡、低分或相近候选保留未知；低分结果须有另一帧高分身份交叉确认。 |
| 战斗头像 | 五个规则排列的头像框。连结爆发就绪时边框可为橙红色；须以至少三个青色框确认位置和唯一间距，五处均有真实的青色或橙红边框。缺框、身份不明仍拒识。长视频加密开场采样；匹配当前目标的短战斗首次取得五人后，以两个已有采样名额就近复核，不增加总帧预算。 |
| 编队/特装页 | 同时确认「队伍编组」「当前的成员」后读取下方五槽；约 2.17:1 横向裁切视频可核验带标题和说明的「特别装备设定」上方五头像。支持布局外保持拒识。 |
| 活动模式 | 分 P 的明确难度可与画面中的模式/阶段编号共同核验。特别战斗＋结算的顶部阶段、剩余挑战次数分数和「再次挑战」须同时明确，才可为同一分 P 后续续刀提供模式范围。结尾战斗记录须有难度标题、模式与挑战次数标签，并在两帧中确认同一来源的完整五人，才可补充该队伍的起始模式；不推断未出现的模式。 |
| 裁切与坐标 | 16:9 及已适配横向裁切布局；身份/SET 坐标投影到同一区域，AUTO 在未裁切原帧右侧独立核验。 |
| 追忆战层数 | 来源按普通记忆领域或具体霸领域、单层隔离。搜索允许目标位于同领域层数合集；解析接受精确分 P、当前帧明确领域和层数，或详情页后的同一战斗：须在 15 秒内进入编队／战斗，战斗首领生命上限一致且计时连续下降，并保留详情页范围证据。已确认的编队及特别装备设定页可保留战前关联；装备页须同时有标题、说明、取消和装备确定，不能单凭标题关联。结果、未知转场、生命上限变化或计时重新开始清除关联；无关联的战斗不得继承上一场范围。限定其他领域／层范围的练度分 P 不补入当前层。未结构化核验的特别装备要求阻止自动开战。 |
| 斗技场回合与成员 | 本期服区、精确回合须明确，地图多个回合或区间标题不能证明当前战斗。单回合详情可在15秒内关联编队，20秒内关联随后战斗；实际战斗成员须与8秒内的最终编队一致。已知加载页仅保留原时限，结果或未知转场清除关联。支持一至五名不同角色，全部身份仍需至少两帧且各有高分证据；少人队伍须确认其余槽为空。选人动画按实际卡片轮廓裁剪，金色战斗卡片须有生命条、规则排列并逐人匹配；没有战斗确认的临时编队不产出方案。强制自动与全员立即发动由该玩法规则留证，不沿用普通战斗的 SET 按钮判定。 |
| 培养 | 头像/完整衣装名与等级、Rank、星数、技能、专武 1/2 等文字明确关联。编队剑徽只在有效信息帧读取，不能套用于战斗星星图案。 |
| SET/AUTO | 五人 SET 和 AUTO 分别留证；「立即／发动」可分行。活动同次挑战中的阶段推进沿用起始模式，继续汇总设置证据，不把后续阶段拆成另一套固定设置。未识别不等于关闭，跨帧开关变化保留冲突，不猜时序。精确本关标题的“全 SET”可留作证据；深渊作者说明中明确绑定当前首领的五位 `O/X` 固定声明按已确认的五槽顺序留证，`O` 开、`X` 关。两者都不能覆盖相反画面，AUTO 仍独立核验。 |
| 视频 OCR 路由 | 表格、编队、培养和不确定画面使用整帧 OCR。确认战斗头像栏后，前两帧及每隔20秒复核整帧，攻略字幕明显变化时追加复核。漏读亮色 SET 时补读按钮区域，同时保留整帧缺失的 AUTO 标签；已有可靠标签不重复叠加，歧义不覆盖。颜色只触发复读，不能授权开关。其余战斗帧只读 SET/AUTO 小区域，遮挡时可凭头像栏颜色维持战斗分类；未识别或低清文字仍未知。 |
| 表格与辅助要求 | 无练度分 P 标题的简单表格也可提取身份；章节范围、例外关卡、属性等级/技能、MP、突破、粉装限制等独立保留。分 P 外说明需明确范围与完整衣装名。 |

明确未覆盖：任意排版、战斗星星的可靠计数、全局培养条件的账号核验、语音/ASR、评论及任意网页图片、复杂手动轴、支援/借角与特殊装备要求的完整结构化、多刀地下城规划。验收缺口只维护在[待办](pending-validation.md)。

大师点 `MP` 数值按培养文字识别，视频文件扩展名 `.mp4` 不表示大师点。明确标注“参考练度”“练度参考”“参考配置”、建议／推荐／可选，或作者自述本人练度与伤害的说明保留为建议，不独立阻止账号试打；同一句包含“必须”“至少”“最低”“不能低于”“不得超过”等必需条件时仍作为要求，前面的推荐措辞不能取消后面的限制。未注明参考的 `MP4` 等数值保留为待核验的全局要求。建议不证明账号伤害达标，也不免除来源已声明的角色培养与操作核验。

战斗右上固定位置的“连结爆发立即发动开启”是游戏状态文案，不能误作作者要求手动发动。此豁免只适用于该位置的完整文案；字幕中的操作要求仍保留，五人 SET 与 AUTO 另行核验。

游戏加载漫画正文不作为作者的借角或操作要求。排除须同时确认右下加载文字、中央浅色边框漫画及两侧黑底；仅排除漫画框内文字，框外作者说明仍完整检查。缺少加载标记或不符合该页面几何时保守保留条件。

### 斗技场

- 范围：合集元数据只提名本期候选。独立分P精确标题（如 `R17`、`R11b`）可声明回合；画面里的 `R17` 可能是 Rank，不作回合证明，与游戏回合冲突时拒绝。`R1-15` 只按请求回合筛选分P，不是 Rank 装备件数；`R38-4` 等培养要求保留。抽帧在预算内均匀覆盖整段视频。
- 回合关联：时限见上表。下列画面只保留原回合与原时限，不提供新回合或成员证明：开战时重现的同回合详情（含徽标完全无法读取的闪现）、数据连接、明确加载及其后1秒内的黑屏或无高分文字暗场、右下暗色加载提示、中央大幅「开始」动画，以及顶部两条总生命值条加中央计时器的开场暗幕（单独计时器或一条生命值条不算）。同回合编队中的「我的队伍一览／呼出此编组」保留回合并清空旧成员，最终队伍由随后的编队给出。已确认的特别装备页在原回合40秒、编队20秒内可关联两秒内返回的编队；超出战斗时限后须在最终编队两秒内重读同一回合详情。结果、其他回合及未知转场清除关联。
- 页面确认：编队页须有标题、当前的成员、战斗效果，以及对手队伍或取消与战斗开始。详情页回合徽标低分或首字误读时，仅在编组详情及挑战目标或战斗效果高分、徽标位于标题右侧时放大复读数字，须与原数字一致且高分才采用。
- 画面几何：上下对称黑边先由中央连续近黑行确认有限边界，再作宽屏裁剪；纯黑加载或非对称暗区不提供边界，OCR证据保留原画面。游戏缩小或横纵比例不一致时，用编队页标题、战斗效果、对手队伍、当前的成员、取消和战斗开始中至少五处唯一文字拟合各轴比例；残差在4个设计像素内且原裁剪偏差超过8像素才采用，沿用到同一分P后续画面，直到下一张编队页重新校准。
- 头像：浅色头像不能凭低饱和度判为空槽；低饱和槽须有真实卡片轮廓及至少0.92的身份匹配，否则整队拒识。金色战斗卡片优先由生命条外框提名，下方TP条不提名；标记与边框粘连时完整生命条外框可补充裁剪。已绑定编队后首次出现战斗轮廓但遮罩妨碍身份时，在原帧预算内把两个后续采样移到0.25秒和0.75秒后；遮罩帧不提供证明。
- 条件：画面培养与操作条件按已确认回合隔离，标题、简介及未定回合的条件共同适用。装备替换页的固定标题、确认正文及取用其他角色装备的提示，只在已核实的控件组合与位置中排除；画外说明与未知装备要求仍保留为未支持条件。
- 结算：WIN／LOSE 大标题须在最近确认的战斗成员后8秒内、于两个不同采样时间高置信度出现，只用于排序：确认胜利优先，仅确认败北不试打，不提供身份或延长时限。新详情、编队或范围冲突清除战果关联。
- 排查：每页 `stadium_observations` 保留原图、逐帧回合关联、编队及战斗成员观察，供定位拒绝原因。

`104角色XXOOO`、`1:04全SET` 等附带倒计时的声明属于中途操作，不能作为固定开关采用；即使放在固定设置之后、用逗号或分号连接，也必须保留为操作要求。首领不明、位数不是五个、额外指令未读懂或不同声明冲突时，保留未知／阻塞；不能因作者另写“自动”而忽略手动轴。

同一深渊视频中的战斗操作按实际首领隔离：须有战斗头像栏或固定位置的菜单／自动控件，并由顶部唯一首领名／等级、计时和生命值共同确认，才可排除明确属于另一首领的操作。首领名与等级可由同一行相邻的两段文字确认。该观察只限定操作条件，不能授权难度或阵容；来源元数据、通用条件、范围未知的说明和未读页面仍保留约束。

## 报告与执行

联动讨伐使用 `collaboration` 分支，按活动实际开放期间及首领身份筛选国服来源，完整读取分 P 和作者补充；附图未解析、页面截断、必要职能精通或其他未支持要求均阻止采用。普通、困难、高难保留来源原标签与首领等级、单次生命上限；较高目标只可在已授权免费首通试打中用于较低目标，不能继承其伤害。固定客户端控件用于服区识别，画外招募广告不能单独证明客户端服区。年份数字不能解释为倒计时操作。

联动画面可在战斗中省略首领名和等级。仅在已核实详情、已知编队／装备及短暂加载的连续转场后，使用全体与单次两条生命值关联：两者差额与上限保持一致，单次生命值不增加，初次关联不超过 15 秒，开始后连续证据间隔不超过 8 秒。未知转场、生命值重新增加或目标冲突清除关联；短暂漏读不提供证据。不能凭全体生命值、视频标题或另一场战斗补齐身份。

解析报告为版本化 JSON，包含来源、目标、获取/解析时间，以及字段的 `value/evidence/conflicts`。证据包含 URL、CID、时间点、方法及保存帧的 1280×720 坐标。`null` 是未知，不能当 `false`；冲突不按最后一帧覆盖。`readiness/pending` 区分已读与缺失字段。

深渊讨伐战的合集分P按首领名字或当前序号筛选候选，序号本身不证明首领身份。搜索结果与指定链接共用作者补充说明读取；完整取得补充后再核验来源的服区、年月和活动属性，作者更正与标题／简介冲突时拒绝。来源适用性、培养要求及服区判定共用同一份带出处的文字集合，不能单独沿用原始标题。明确注明前哨或第几位首领的条件按目标应用，未注明范围的条件保留为共同要求。

深渊要求按接口分页总量完整读取可见主评论与楼中楼，并核对去重后的数量。默认每个来源的主评论和楼中楼合计最多请求 10 页，`sources.max_comment_pages` 可设为 1～100；每次请求前检查任务中止及解析时限。分页数量变化、重复或缺页、未知响应、请求失败、超过预算都不能获得完整扫描标记，也不能授权战斗。完整读取后仍须核验作者补充，成功取得空评论与读取失败分别处理。失败或仅含首屏线索的缓存不会作为深渊的完整来源复用，下次请求重读；完整结果才可复用。作者评论附图尚未解析，含附图的来源在读取解析缓存前就拒绝；不能按空正文或正文标注的其他首领推断图片无关。

来源标题、简介和作者补充按当前目标检查完整的手动、借角及操作轴条件，和分 P 标题／画面文字共用判断规则。深渊来源的 `AUTO关闭`、`角色关SET`、`SET OFF` 等开关声明尚未结构化为设置事实，保留为阻塞条件，不能忽略作者更正后沿用视频开关。检查按语句关联开关名称与控制动作，不要求紧邻，也不依赖“全程”“始终”等修饰词名单或字数上限。生产入口跳过明确不支持的来源媒体；分析时即使允许下载，条件仍保留在 `manual_actions` 中并阻止采用。

深渊元数据已声明当前目标尚未支持的必需培养或装备条件时，在下载前停止该来源的逐帧解析。按语句分别保留原文、标题／简介／作者评论编号与建议或必需状态，不能将作者参考练度扩展为整份攻略的硬条件。明确属于其他首领的条件不影响当前目标；分 P 中才出现的条件仍按方案范围隔离，不因一个方案不可用而跳过同来源的其他方案。元数据、分 P 标题和画面文字使用同一套建议判定。

文字来源中的完整衣装名与明确培养字段按首领、难度和方案编号绑定；星级、Rank、等级、技能及专武数值复用画面培养字段解析，保留原文、来源及作者评论编号。数值与视频冲突时拒绝采用，不自动用作者更正覆盖旧值；未知衣装、多角色混写或无法完整理解的培养声明保留为阻塞要求，不能只提取其中一个字段后丢弃其余条件。未解析出数值不代表没有要求，例如“三星”“专武已装备”仍需保留为阻塞声明。明确的练度比较或建议可保留为建议；不能因一句“大师等级低了”将整段回复变为角色培养要求。“技能要满”“等级至少……”和引用未解析图片等指令仍阻止采用。

首领限定须读取完整的编号列表与区间，例如 `Boss1/Boss2`、`Boss1-3`、`1-3王`；不能只按第一个编号丢弃其他目标的条件。同一行的独立句子先按分号、句末标点等分开，再判断每句范围；未可靠拆分且仍含其他首领标记的句子保守保留。无法明确排除的组合按共同要求保留，多方案列表／区间也不能被误判为只属于第一个方案。

除明确属于其他战斗的分 P 外，深渊来源的每一页都可能含有必要条件，必须完整纳入解析，包括“必看”“前言”、空标题及其他未识别标题；不能依赖说明关键词筛选。超过页面预算时拒绝该来源。共用或未知范围的培养及手动条件默认适用于当前候选，同编号方案的独立说明也须保留。只有当前方案编号明确时，才能隔离明确标为其他编号且未声明通用的条件；当前队伍所在分 P 的条件始终保留。完整衣装名关联的培养数值和头像表格也按这套范围规则归属，保留两帧数值证据，不能因说明页没有关卡画面而忽略。任一已选页面下载失败、跳过、按时长截断、画面读取失败、文字无法可靠读取或布局不支持时，保留“未完整解析”的条件并按同一范围规则阻止采用。

深渊讨伐战的参考伤害取同一已核验阵容所处分 P 的明确伤害或击杀刀数，保留标题、来源链接、分 P 与真实难度。数值须与“伤害”或“输出”直接关联；粉丝数、玛那、生命值、首通额外分数及没有语义标注的万／亿数值均不能当作伤害。刀数须有击杀／打完语义，且同一来源生命上限可见才可换算；含多个冲突数值时不采用。不同首领或另一方案的宣传伤害不能补入。名字和等级可分成两行，完整名字仍须高置信度精确匹配，截断名字不能证明身份。账号替补后清除原攻略参考伤害；账号本次免费模拟的伤害与来源参考分别记录，不互相覆盖。是否实战由[深渊指南](guides/abyss-subjugation.md)中的存活、剩余血量和刀数预算决定。

专武安装开关与强化数值分别保存：`unique/unique2` 表示安装，`unique_level` 为专武 1 等级，`unique2_stars` 为专武 2 强化阶段。来源未声明数值时不凭空补阈值，声明了数值则保留证据并在账号核验时检查；明确的专武 2 零阶段不表示未安装，也不能当作角色零星。解析器升级会重新核验旧解析缓存。

完整来源方案要求等级、Rank、星数、专武 1/2、技能、五人 SET、范围、服区明确，且无未支持的全局要求或手动轴。活动首领、追忆战场与深渊讨伐战支持有证据的固定 AUTO 开启或关闭，战斗菜单按来源核对；其他解析路径仍要求 AUTO 固定开启。战前还须核验账号，Rank/星数较高不自动符合精确要求。`ready` 不保证无遗漏或能通关。

所有 `local_trial` 均保留缺失字段、假设、账号观察与 `build_basis`，不把账号现状补写为攻略要求。未知目标或身份不得开战；发现队伍不自动开启首领战。支持旧队伍文件的任务仅在显式 `use_local_teams: true` 时回退；深渊没有此回退路径。

活动原阵容实测可同时设置 `allow_local_trials: true`、`allow_party_variants: false`、`require_source_settings: true`：只保留服区、范围、五人 SET 和固定 AUTO 都明确且无未支持要求的来源队伍；战前另核对实时等级、Rank、星数、技能和专武。无剑徽的角色由人物页核验是否尚未实装专武，返回后重新确认首领模式、重选来源阵容并复核培养未变化。来源未给的培养阈值仍记未知，不宣称完整复现。

## Agent 复核

显式允许深渊账号试打时，同一首领较低难度的已核验来源可作为较高难度的免费模拟种子。来源仍记录原难度和明确培养要求，不能改写为高难度攻略，也不继承原伤害参考；当前目标必须已解锁并由详情核对，免费模拟须通过玩法任务的存活与刀数验收。此路径不适用于前哨，不跨首领或活动期。

明确允许账号试打时，追忆及深渊首领可将视频战斗的高置信度首领全名、等级、生命上限和有效计时，与本次运行读取的详情对应。深渊保留同一首领已核对难度的详情，视频须唯一匹配其中一档，并保留来源真实难度；其他首领、未知或歧义范围不能沿用。证据同时保留对应详情与视频帧，缓存复用时绑定该难度的新详情。此路径始终标为 `local_trial`，跨难度按前述免费模拟门槛核验，不能把来源改标为当前难度。

深渊的公开评论优先使用游标分页接口；到达终页时以去重主评论数加全部楼中楼计数核对总量，再补齐作者楼中楼。摘要接口仅返回热门评论时不能充当完整扫描。无评论的终页缺少总量时，须另由带总量的接口确认零条；未知终页、游标循环和数量不符均阻止采用。

视频中单独出现的“要借用这个角色吗？”对话框只证明来源曾打开借角确认。显式允许深渊首领账号试打时，可保留该观察并核验本账号持有的全部五人，再免费模拟；不自动借角，不继承借角培养。作者声明必须借角或其他操作要求仍阻止采用。

检查报告对应的原始帧、OCR 和游戏结果，也检查被拒绝/跳过的画面，避免遗漏额外条件。不能以 `complete/ready`、截图存在或进程退出替代业务验证。复核证据保存在忽略的 `cache/agent/strategy-reviews/`，关联报告路径与 SHA-256；报告改变后重新核验。

发现问题应修复正式识别模块并使用合成回归；人工改数据不等于程序支持。文档只保留当前规则与未完成待办，不追加逐次解析、运行或修复记录。
