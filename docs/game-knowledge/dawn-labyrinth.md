# 黎明界迷宫

**证据范围：国服实测，雷电 960×540，2026-10-01～04。** 以下出发、探索、首领和通关机制限于美食殿堂难度 1；其他公会、难度及未见页面见[待观察状态](pending-validation.md)。跨服资料单独标注。

## 入口与通行证

首页 → 冒险 → 黎明界迷宫。入口位于冒险页右下方；迷宫首页有“出发”“阿尔法强化”“任务”“报酬一览”“商店”“遗物图鉴”，右上角有“玩法”“帮助”。“出发”卡片下方以 `持有量/99` 显示通行证。

| 页面或状态 | 可见内容与去向 |
|---|---|
| 公会选择 | 首页“出发”进入“请选择要同行的公会”；卡片底部“选择”进入普通探索，右上角另有“难度变更”和“跳过”。 |
| 难度变更 | 列表、取消、变更；未解锁难度灰显。 |
| 跳过未解锁 | 灰显按钮提示“通关1次难度1后可解锁。”；该提示不证明其他公会或难度的跳过条件。 |
| 公会选择确认 | 美食殿堂出发消耗 1 张通行证，显示消费前后数量；取消、难度变更、出发是独立操作。 |
| 保存的探索 | 首页仍显示“出发”；点击可直接返回保存的首领编队，无新的公会选择或消费确认。 |

**国服实测（2026-10-04，美食殿堂难度 1）**：持有量为 `0/99` 时仍可选择公会，出发确认显示“由于未持有迷宫通行证，无法获得报酬。”，蓝色“出发”可用。国服游戏内“帮助 → 黎明界迷宫 → 关于黎明界迷宫”也明确说明零票可挑战，但无法获得迷宫报酬、完成相关任务及解锁新的迷宫难度；零票实际探索、结算及通关记录的变化仍待观察。

**台服官方资料：**[黎明界迷宫 β 版公告](https://www.princessconnect.so-net.tw/news/newsDetail/3573)说明零通行证仍可挑战，但不获得报酬、不计入任务、不解锁下一难度，也不计入通关次数。这些结算限制是跨服参考，尚不能作为国服实测结论。

## 伙伴与探索

出发奖励之后进入“角色选择”，初始可邀请三名伙伴。列表含所选公会角色的不同衣装，卡片右上角数字为尚未提交的选择顺序。邀请后显示角色展示和“角色加入”回执。

长按角色卡片可看等级、Rank、星数和技能；详情标题可能省略衣装。详情有属性值、技能与简介，未展示普通装备槽位及专武详情。Rank 不能证明六件普通装备已穿戴，迷宫头像的专武标记规则尚不明确；身份与装备系统见[角色知识](characters.md)。

**国服游戏内帮助（2026-10-04，NPC 角色）**：未持有的角色也可作为 NPC 招募。NPC 的等级和技能为 320、Rank 34、三星；已开放六星的角色为六星。已实装的专武 1 为 Lv30、专武 2 为零阶段。NPC 不装备特别装备，之后也不能为其装备。

已持有角色只要符合任一条件，也会以 NPC 登场：已开放六星但当前五星及以下；未开放六星且当前一或二星；等级 319 及以下；Rank 33 及以下；专武 1 未装备或 Lv29 及以下；专武 2 未装备。专武条件仅适用于已实装对应专武的角色。角色属性在招募时确定；之后修改账号培养不能直接推断已招募伙伴随之变化。上述帮助未说明普通装备槽位的穿戴状态，具体招募详情及标记仍须核对。

地图显示区域进度 `1/3` 至 `3/3`，可行动节点以明亮蓝色高亮。底部“撤退（无报酬）”和“返回（有报酬）”会结束探索。右上角菜单包含角色、迷宫遗物、难度详情、设定、玩法和帮助；难度详情图标显示难度数字，菜单没有同行公会名称。

| 节点或奖励 | 页面与机制 |
|---|---|
| 战斗 | 点选可出现“移动目标确认”，也可能直接进入敌方详情；详情列出魔物等级、查看地图和挑战。挑战进入队伍编组，战斗开始才开战。 |
| 普通魔物 | 信息按钮打开名字、生命值和技能说明；美食殿堂难度 1 的区域 2 普通魔物比区域 1 高 10 级。获胜显示 `WIN`，随后出现下一步。 |
| 角色加入奖励 | 三名候选、剩余选择次数；完整衣装名可分两行。加入储备伙伴不会自动替换当前队伍。 |
| `EVENT` | “触发事件”有多项选择，每项分别列出收益或代价。“这里是公会管理协会”含随机印记和阿尔法金币奖励；“在地下城迷路了”含仅金币项与概率项。 |
| 迷宫遗物 | 发亮的无文字节点可进入遗物选择；“获得道具的机会”列出三件遗物、剩余次数、印记与效果，包括攻击力百分比和生命值吸收增加。灰色选择按钮不可用；区域末端的选择可进入下一区域。 |
| 商店 | 用阿尔法金币购买或更新商品。关闭打开“商店确认”，确认退出后该格子不能再次进入，随后返回地图。 |

普通魔物详情先展示分类与介绍，再以“·”列出行动与特殊效果。分类可包含物理、魔法、回复、防御、范围或干扰；介绍也可能描述攻击和防御特性。近身攻击类可另列“造成伤害所获得的技能值回复量降低80%”；回复类可列全体回复。击退、撞飞或眩晕附注“在伤害免疫的情况下也会成功赋予”描述这些效果可穿过免疫，不表示魔物自身拥有伤害免疫。烧伤、中毒的伤害是否回复技能值也有独立条目，不能只看首项攻击。

## 难度 1 的最终首领

区域 `3/3` 终点以紫色高亮标记“首领”，移动确认称“首领战格子”。暗黑滴水嘴兽及随从为 350 级，首领生命值 6000 万；有效效果列出坦克型、物防下降和魔防下降。

魔物详情可滚动查看技能：技能伤害不回复技能值；烧伤伤害取决于自身双防；降低生命值吸收；全体魔法伤害与击退；前排固定魔法伤害。

| 状态 | 页面与判断依据 |
|---|---|
| 编队 | 队伍 1～3，黄色标签标记当前队伍；右下角依次进入下一队，第三队显示战斗开始。允许空队伍。 |
| 接战 | 已确认第一队时间耗尽后，第二队自动接战并继承敌方剩余生命值；第二队获胜直接进入 `WIN`，第三队不参战。第二队到第三队的接续待观察。 |
| 最终失败 | “战斗失败”列出各队结果、伤害报告、结束和重新挑战。失败时角色可能仍存活，中间队伍时间耗尽也不表示整场结束。 |
| 伤害报告 | 按角色汇总造成和受到的伤害，底部确认；未单列首领受到的伤害，不能直接当作首领生命值减少量。 |

## 通关与跳过

通关结算顺序为：`RESULT` 角色和遗物清单 → 下一步 → `CLEAR` 分数与难度奖励 → 关闭 → 宝箱开封结果 → 确认 → 难度解锁。难度 2 解锁后会自动被选中，难度列表也可能滚动，需向上查看难度 1。

美食殿堂难度 1 通关后，“跳过”打开“可跳过的公会一览”，其中列出美食殿堂。零通行证也能查看该列表。

| 页面 | 控件与确认内容 |
|---|---|
| 可跳过的公会一览 | 每行显示公会、迷宫、难度与勾选框；有解除所有勾选。底部显示消费前后通行证、每公会使用数量、MIN、减号、加号、MAX、取消和一键扫荡。勾选后才能启用扫荡。 |
| 一键扫荡确认 | 公会、难度、各行次数、消费通行证、当前余额、公会数量及合计次数；挑战提交扫荡。 |
| 扫荡结果 | 跳过次数、通关次数，动画结束后确认。退出公会列表有“报酬确认”，关闭后回首页核对通行证；用尽显示 `0/99`。 |

**台服官方资料：**[黎明界迷宫 β 版公告](https://www.princessconnect.so-net.tw/news/newsDetail/3573)说明，扫荡要求对应公会已通关该难度。这是跨服参考，国服其他公会和难度的条件仍以页面为准。

## 迷宫任务奖励

首页“任务”的数字角标表示可领取奖励。任务页有全部、普通、公会三个标签；完成项为蓝色“收取”，“全部收取”领取当前奖励。通行证为零时也可领取。

领取回执标题为“收取报酬”，正文“获得了以下报酬。”，底部关闭。返回后已领取项目移除，未达成项目可显示挑战；无奖励时全部收取灰显。取消返回首页，任务数字角标消失。

列表常驻说明超过持有上限的道具将送往礼物箱；该说明不表示当前已满仓。实际溢出的回执和礼物箱去向列于[待观察状态](pending-validation.md)。
