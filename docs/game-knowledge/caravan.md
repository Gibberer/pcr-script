- 另一同伴效果“可重掷1次骰子”，左侧圆按钮为当前点数、右侧“重新投掷”。当前策略保留4～6点或已足够到达的点数；1～3点且尚不足到达时重掷一次。辅助“+3格子”不能直接加在按钮点数上估计实际位移，实测显示4点时实际只走4格，故决策仅用可确认点数。
