# 驾车游

适用：国服雷电模拟器 960×540；2026-09-21 实测。入口：首页 → 冒险 → 驾车游。地图显示经过回合、检查点距离和骰子余额。

## 骰子与检查点

- “同时掷 3 个”开关蓝底为开、白底为关。游戏说明：开启时消耗 3 骰子和 3 回合，仅第三个落点触发格子效果。
- 同一赛季曾在 15 回合内到达检查点后解锁“区间跳过”。2026-11-04 实测（赛季最快纪录 9 回合）：本区间超过 6 回合后点击跳过只提示“由于已超过6回合，在到达下一个检查点之前无法跳过。”，须单骰到下一检查点；回合门槛随赛季或纪录变化，以提示为准。区间跳过一次消耗 15 骰子，确认页显示消费前后余额；结算含奖励、鉴定与金币等页面。
- 骰子余额为 0 时数字徽标可消失，不显示 0。需结合灰显和“未持有骰子”提示确认；未读到数字不能当作 0。
- 活动加成可返还骰子；余额变化不一定恰好等于投掷消耗。

## 地图事件

- 分岔出现两条“距离检查点”和箭头；短距离不保证一定更快达标。
- 料理、同伴效果、接水果游戏、宝藏、抽奖及里程商店可插入投掷与结算。同伴效果可能提供重掷、追加投掷或正反面选择，不能误认作三骰开关。
- 某些料理会跳过下回合计数；未知料理效果不作推断。近道可要求支付里程。
- 多份料理可超过容量并出现强制出售页。2026-11-04 实测：页面标题“持有的料理”，提示“持有数已满。请选择要出售的料理。”及“料理持有数13/10”（文字顺序也可读作“持有料理数”），只有各卡“出售”与“一键出售”，无关闭按钮；逐份出售确认后数量递减，每份 500 里程，回到 10/10 时显示“出售完毕”并返回地图。「若菜的节俭八分饱咖喱」效果为本回合骰子点数必定为 8。检查点结算可能连续出现回合奖励、鉴定、金币及抽奖。

验证边界：单骰到检查点、连续区间跳过、超回合跳过锁定、料理满仓逐份出售及清骰至零骰已实测（2026-11-04）；新赛季及未知格子待观察。
