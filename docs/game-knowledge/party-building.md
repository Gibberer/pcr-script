# 配队与战前检查

适用范围：角色与特别装备的国服观察范围为雷电 960×540，2026 年 9～10 月；下面的通用系统引用日服官方帮助时单独标注。各期首领和加成以当前关卡为准，不能将某次成功队伍视为通用最强队。

## 攻略是否适用

攻略的服区、活动期、目标首领、难度、角色衣装和战斗操作共同决定适用范围。同名基础角色可能有不同衣装，AUTO 和每人 SET 也分别影响操作；核对方式见[角色](characters.md)。深渊的模拟战和实战区别、首通标记及伤害回执见[深渊讨伐战](abyss-subjugation.md)。

**配队判断（基于上述国服页面与机制的推断）**：先检查攻略原阵容能否完整组成及练度差距，再考虑替补。攻击类型和治疗／坦克等职能相似只能提出候选，不能证明技能范围、破防量、TP 时序和存活相同。替补后的伤害不得沿用原攻略宣称的结果；有免费模拟的关卡应以新阵容实测判断。这个判断不是任何特定替补组合已经通关的证据。

## 影响强度的不同部分

| 项目 | 战前要区分的状态 |
|---|---|
| 身份、等级、技能 | 衣装必须一致；身份确认不代表技能等级达标 |
| 普通装备与 Rank | Rank、当前装备件数与装备强化分别核对；更高 Rank 不自动等价于攻略的精确 Rank |
| 星级 | 当前设置与已解锁上限不同；“可设五星”不意味着当前已为五星，攻略低星不能随意拉满 |
| 专武 1 | 是否开放、是否安装、当前强化等级、强化上限分别判断；已经安装不代表达到攻略等级 |
| 专武 2 | 独立检查开放和安装，再核对强化阶段；不能用专武 1 的图标或等级代替 |
| 特别装备 | 与专武不同；三槽占用、实际分配的装备及攻略限制都相关，槽位全满不证明配装相同 |
| 好感度、角色剧情与属性强化 | 剧情解锁不等于已领取属性奖励；全局培养条件不能由角色等级代替 |

角色、星级和好感度的依据统一见[角色系统](characters.md)；特别装备的分配与回执见[礼物与特别装备](gifts.md)。这些项目有不同资源和确认步骤，不能因某一项达标推断其他项已完成。

**日服官方资料（2026-10-03 核对）**：专武 1 需要角色 Rank 7 以上；专武 2 以已装备专武 1 为前提。专武安装后不能卸下。专武 1 使用强化等级，专武 2 使用强化阶段，后者上限为五阶段。[Cygames 官方帮助](https://dmg.priconne-redive.jp/help/)。国服具体角色是否开放、材料和消费页面仍以游戏为准，不能照搬日服实装时间。

**来源术语与待国服核实项**：“专武 2 零星／零阶段”描述强化程度，与“未装备”是不同声明；不能把数值零直接解释成没有该装备。国服未安装、刚安装和各强化阶段的可见标记与材料回执仍见[待观察状态](pending-validation.md)。

## 调整的判断顺序

**使用者提供的攻略记法（2026-10-06）**：五人攻略中的 `O` 表示开启 SET，`X` 表示关闭 SET，按攻略所列五人顺序对应；`OXOOO` 表示第二人关闭，其余四人开启。这是攻略约定，不是界面缺少 SET 标记就能认定关闭。附带倒计时的多组记法表示战斗途中切换，须与固定初始设置区分；AUTO 另行核对。

**配队判断（推断）**：先查漏装、未知培养及来源明确差距，再区分生存失败与输出不足。已有特别装备的合理分配可能改善当前阵容；游戏“自动装备”给出的是当前设置下的分配建议，不证明它满足攻略限制或达到全局最优。补装专武与继续强化专武也不能混为一步。任何改变身份、培养、SET/AUTO 或配装的操作，都会使之前的战果只能作为参考，需重新观察当前组合的表现。
