# 团队战

适用范围：国服 2026-09 团队战，960×540 界面。未标为实测的机制来自玩家提供，仍需在自然出现的实战状态核对。

## 入口与页面

**国服实测（2026-09-24）**：从首页的「冒险」进入「团队战」。本期地图显示活动时间为 09/24 05:00～09/28 23:59（国服时间）。地图有五个首领位置，各位置显示自己的轮次；地图显示剩余挑战次数、额外挑战次数和当前 CP。点击首领打开「魔物详情」，可看到名称、当前/最大生命值、模拟战与实战切换、挑战入口。实测地图同时显示第 2 轮和第 3 轮首领。

**国服实测（2026-09-25）**：行会其他成员击败场上首领后，地图可短时只显示「已击败！」宝箱而没有任何轮次标签，个人剩余挑战次数仍为 3。随后出现包含行会讨伐奖励的「报酬确认」，确认后出现「首领魔物等级（难度）提升」通知；关闭通知、等待地图刷新后，五个首领重新显示第 7 轮及生命值。此过渡态不代表个人挑战次数耗尽。

首次进入时连续出现两个弹窗、各有关闭按钮，**玩家提供，待自然复核**。已经进入过活动时不会重现该场景。

## 推荐编组与战斗

**国服实测（2026-09-24）**：首领详情右上角的「推荐编组」有「高级」标签。每条推荐显示五个角色头像、参考伤害和预计「讨伐时间」，并提供「使用」按钮；未持有角色会在对应头像位置显示空白/「未持有」，已参战角色的头像直接标「限制实战使用」。列表应在队伍条目区域滑动。选择一条推荐后进入五人编队，可设置特别装备。普通模拟战结算会标明模拟结果不计入团队战战绩，显示伤害比例、返还时间和「下一步」。模拟战结束后，从同一首领直接进入实战编队，已选的五人会保留；当前已在五人头像上核对一致。

**国服实测（2026-09-25）**：第 3 阶段冰霜魔狼当次生命值 70,000,000，所选高级推荐的参考伤害也是 70,000,000。模拟战 RESULT 显示实际伤害 35,671,598、伤害比例 50.96%、魔物剩余 34,328,402/70,000,000 和「下一步」，没有显式的失败字样。关闭模拟结果后地图剩余挑战次数仍为 3。

**国服实测（2026-09-25）**：高级推荐列表中的头像区域长按会打开角色强化页；从左侧「参考伤害」文字区域向上滑动可滚动队伍列表。返回角色强化页后可回到原推荐列表。

**国服实测（2026-09-26）**：高级推荐每行右侧有「保存队伍」勾选框，列表中可同时出现已勾选和未勾选的条目。列表底部的队伍可能只露出「使用」按钮，讨伐时间被底栏遮住；从参考伤害文字区域每次向上短滑约 100 像素后，原来的第二行可完整显示，再滑一次可完整显示第三行。是否保存队伍与「使用」是分开的界面操作。

**玩家提供，待其他自然状态复核**：参考伤害等于当次首领生命值表示预期击杀；参考伤害低于生命值表示预期伤害数值。应以模拟战的实际伤害或击杀结果核对该目标，不能仅凭是否击杀判断一条推荐是否达标。

**国服实测（2026-09-24）**：一次普通挑战击杀后，地图的剩余挑战次数从 3 变为 2、剩余延长次数从 0 变为 1。结算后先显示挑战报酬、再显示「报酬确认」和「剩余时间返还通知」；通知中明确给出下一场可使用的时间。新一轮同位置首领随后出现在地图。点击任一可见首领挑战时，如有延长次数，会弹「确认使用延长时间」：上方是延长挑战及已经参战的五人，下方是消耗普通挑战次数的入口；勾选「使用延长时间时，会编入已参加角色」后，延长编队保留原五人。延长模拟战胜利页不显示普通战的返还时间。延长实战前另有「团队战开始确认」，提示这次将消耗返还时间。

同一五人完成一次普通挑战与一次延长挑战后，地图实测普通次数仍为 2，延长次数从 1 变为 0。延长挑战击杀未获得第二次延长次数。当天三组不同五人队伍分别完成普通与延长挑战，最终地图显示普通次数 0、延长次数 0。最后一次战后会先在地图上方播放宝箱动画，此时地图文字仍可见但不可读取次数；待「报酬确认」关闭后再核对。

**国服实测（2026-09-24）**：已参战角色在后续编队列表与底部已选头像上显示「已参加团队战」。延长挑战勾选沿用选项后仍可使用相同五人。**玩家补充，待自然复核**：已参战角色仍可参加新一轮普通模拟战，但不可用于新一轮普通实战；因此模拟胜利后仍须核对已参战标记，只有延长挑战可沿用这组角色。

**玩家提供，仍待复核的范围**：消耗体力达到条件后可得到三次普通挑战；返还时间在原剩余时间基础上加 20 秒；新一轮超过场上最低轮次两轮时暂不显示；实战进入后不能退出。当天普通挑战从 3 次用到 0 次，延长挑战每次获 1 次并消耗 1 次，均已实测。

推荐的预计时间仅供筛选；实际伤害、能否击杀和能否接续第二次挑战，须以当次模拟战结算核对。优先选择满血且下一轮可见的首领，试用持有且未被占用的推荐五人，特别装备装满后核对模拟结果，再确认实战编队未变化。
