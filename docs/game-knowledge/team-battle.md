# 团队战

适用：国服 2026-09～10 团队战、雷电模拟器 960×540；页面结论来自 2026-09-24～28、2026-10-25～27 实测。玩家提供但未核实的规则单列，不作为已验证条件。

## 入口与地图

- 首页 → 冒险 → 团队战。地图有五个首领位置，各自显示轮次，并列出普通/延长挑战次数和 CP；不同轮次可以同时出现。
- **国服实测（2026-09-28）**：当日首次进入首页可弹出「9月团队战最终日！」提示，显示活动结束时间与剩余挑战次数；底部「关闭」返回首页，未勾选“不再显示”也可关闭。
- 首领的「魔物详情」显示名称、当前/最大生命值、模拟/实战切换及挑战入口。
- 行会成员击杀后，地图可短时仅显示「已击败！」宝箱，没有轮次标签。处理「报酬确认」「首领魔物等级（难度）提升」并等待刷新；此过渡态不代表个人次数耗尽。
- **国服实测（2026-10-25）**：查看推荐或准备模拟期间，目标被行会成员讨伐后可显示「错误提示／该怪物已被讨伐。」，居中底部为「确认」，背景仍可见推荐列表；此时旧首领状态不可继续沿用。

## 推荐编组与模拟

- 详情右上角「推荐编组 → 高级」列出五个头像、参考伤害、预计讨伐时间与「使用」按钮。缺员显示空白/「未持有」，已参战角色可标「限制实战使用」。
- 头像区域长按会进入角色强化页；从左侧参考伤害文字区域向上滑动可继续查看后续队伍，底栏可能遮住讨伐时间。「保存队伍」勾选与「使用」分开，列表可同时有已保存/未保存条目。
- **国服实测（2026-09-28）**：高级推荐列表可连续下滑多屏，右侧滚动条标示当前位置；已观察的多屏位置右下角均有「列表更新」按钮。列表更新后是否更换推荐内容、是否回到顶部仍待自然观察。
- **国服实测（2026-10-28）**：「隐藏角色」打开「隐藏筛选」，说明为「在推荐编组中排除含有所选角色的队伍，并进行显示。」；左侧角色卡可显示「限制实战使用」，选中卡变暗、右上出现黄色勾，勾的右上端伸出卡片右边框；选中后条幅照常闪烁，右侧已选槽位也显示条幅。右侧共10个槽位（4＋4＋2）。橙色或金色头发可在卡片右上角框内呈现与勾相近的颜色。连续点选或移除时，个别点击可在列表更新期间未生效，画面保持点击前状态。「限制实战使用」条幅周期性淡入淡出，约2秒一轮，各卡同步；同一静止画面的连续截图可依次为无条幅、完整条幅和半透明条幅，单张截图不能证明该卡未受限或已选中状态。从左侧角色列之间的空隙滑动可继续查看角色，最右侧空白边缘滑动未生效。「显示更新」应用选择并返回列表。排除受限角色后出现了默认列表中未见的队伍，因此默认列表到底不证明没有其他可用推荐；这也不保证新队伍的实际伤害达标。
- 使用推荐后进入五人编队，可设置特别装备。模拟结束后再进入同首领实战编队时可保留五人，仍需重新核对。
- **国服实测（2026-10-28）**：推荐五人编队点「取消」返回推荐列表；恢复隐藏筛选后关闭列表，再由魔物详情点「挑战」，可保留此前选择的五人。右侧已选隐藏角色可逐个点选移除；恢复筛选只影响推荐显示，不证明五人或特别装备仍然相同，仍需核对。
- **国服实测（2026-09-27）**：编队下方五个头像均存在时，角色名可能贴近头像边缘；须结合头像核对人数。火属性图标及角色立绘可令卡片底部呈红色，这不表示已参战；已参战卡片有「第几战／已参加团队战」文字，条幅颜色可以不同。
- **国服实测（2026-10-25）**：使用推荐时模拟编队可为完整五人，转入同首领普通实战编队后却只保留四人，红色空槽显示「未编组」，右下明确提示「编组成员不足5名角色。」；也观察到五槽全空、总战力为 0 且没有不足五人文字的状态。模拟编队完整不证明普通实战仍可使用全员。
- 普通模拟 RESULT 说明不计入战绩，显示实际伤害、比例、首领剩余 HP、返还时间和「下一步」。未击杀时可能没有明确“失败”字样；不能只看按钮判断达标。已观察模拟结束后普通挑战次数不变。

## 普通与延长挑战

- 已观察普通击杀结算依次包含挑战报酬、报酬确认和剩余时间返还通知；普通次数减一、延长次数增一。返还通知给出下一场可用时间。
- **国服实测（2026-10-27）**：普通模拟击杀前战斗计时约为0:30，胜利结算「返还时间」为0:50，普通实战同样返还0:50；该数包含额外20秒，并非第一刀的原剩余时间。按90秒普通战预算估算击杀耗时须使用 `90+20−返还时间`，返还到90秒上限时该估计保守。返还50秒不能据此认为同样的第二刀只需40秒。
- 有延长次数时，挑战入口弹出「确认使用延长时间」：上方为延长挑战与已参战五人，下方是普通挑战入口。勾选「使用延长时间时，会编入已参加角色」可沿用五人。
- **国服实测（2026-10-27）**：已有延长次数时，推荐列表点击「使用」也会先打开上述弹窗。取消自动编入已参加角色的勾选后，可保留推荐的新五人进入延长模拟；同样的五人与特别装备可在50秒延长实战击杀第8轮双足飞龙，普通次数保持2、延长次数1→0。胜利页明确提示延长战无法获得挑战报酬；这些新参战成员在其他普通推荐编队中可显示「限制实战使用」。
- 延长实战前的「团队战开始确认」提示消耗返还时间。已观察延长战消耗一份延长次数、不再扣普通次数；延长击杀未再获得延长次数，延长模拟胜利页也不显示普通战的返还时间。
- 已参战角色在列表和已选头像上显示「已参加团队战」，延长挑战可沿用。地图宝箱动画和报酬确认结束后再读次数，不能用动画期间的缺字判断归零。
- **国服实测（2026-10-25）**：第一轮双足飞龙普通实战击杀后，普通次数 3→2、延长次数 0→1；同队延长挑战击杀第一轮巴吉里斯克后，普通次数仍为 2、延长次数 1→0。双足飞龙已显示第二轮时，其他首领仍可处于第一轮；轮次标签的纵向位置随首领位置不同。

## 玩家提供、待复核

团队战按阶段提升首领难度，阶段依次为 A、B、C、D 等；对已有较强阵容的账号，A/B/C 阶段一队可轻松连续击杀两个首领，D 阶段起才开始需要精确配队（玩家提供，各阶段对应轮次未核实）。

模拟战不限制挑战次数（玩家提供）。该规则与普通、延长实战的每日次数独立。

参考伤害等于当次首领生命值表示预期击杀；低于生命值时表示预期伤害数值。应以模拟战的实际伤害或击杀结果核对，不能仅凭是否击杀判断达标。此解释来自玩家提供，仍需其他自然状态复核。

首次进入有连续两个弹窗；消耗体力满足条件后可得三次普通挑战；新一轮超过场上最低轮次两轮时暂不显示；实战进入后不能退出；已参战角色可参加新的普通模拟战但不能参加新的普通实战。自然观察条件见[待观察清单](pending-validation.md)。
