# 地下城

适用：国服雷电 960×540；2026-09-22 实测。入口：首页 → 冒险 → 特别关卡 → 地下城。

## 区域与楼层

- 难度卡片的“已完成！”只证明对应区域通关。选区确认提示撤退前不能更改区域。
- 入区后当日进入次数可从 1/1 变 0/1；已进入的挑战仍能继续。地图显示当前楼层，如 1/5 阶。地图“撤退”退出整个区域，与战斗菜单撤退不同。
- 实测“四彩的灵峰”前四层为普通敌人，第五层为首领。结算含宝箱/奖励动画和地图移动；稳定后再看当前层。最终通关以目标难度卡片“已完成！”为证。
- 存活角色在前两层可再次选择。第五层参战角色结算后从可用角色数扣除。支援卡可能有费用；借用流程未实测。

## 第五层首领

- 已见春临、炎夏、爽秋、寒威阶段。时间耗尽可显示“战斗失败”，但伤害保留且区域未重置。返回地图核对首领名、剩余 HP、可用角色数。
- 阶段不按每战固定轮换：炎夏曾连续出现；寒威未换季时仍保留伤害。不得凭战斗次数或 HP 猜阶段。
- 一次战斗菜单撤退后实测 HP 和可用角色数不变；未结算的临时伤害不计入保留伤害。
- 特别装备按五人、每人三槽设置；自动装备可能取其他角色装备，稀有度排序不代表对当前首领最优。

来源边界：[GameWith 首领说明](https://gamewith.jp/pricone-re/article/show/449820)为跨服攻略，换季和耐久策略须按国服当前阶段核对。未知：其他难度、新区域、支援借用、首通后扫荡规则。
