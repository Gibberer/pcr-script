# 斗技场

适用：国服雷电 960×540。回合制斗技场与常驻「竞技场」「公主竞技场」不同。

**国服实测（2026-10-11，本期 10/09 12:00～10/13 23:59）**：首页 → 冒险 → 左下圆形「斗技场」。地图顶栏显示解锁回合及累计星数；本期共18回合、54星，初始解锁1回合、0星。每页三个回合，右侧箭头翻页，卡片底部为三个星级槽及首通报酬。

回合卡片打开「编组详情」，显示敌方五人、等级、挑战目标、战斗效果及初次通关报酬。「挑战」进入未开战的「队伍编组」，「战斗开始」才提交；取消编队回详情，再取消回地图。

**国服实测（同日，编队与第1回合战斗）**：编队上方有对手信息，角色筛选栏位于其下；列表向顶部下拉后显示搜索栏，选中成员仍位于底部五槽。可使用两名角色出战，其他槽保持空白。战斗自动进行，战斗头像为金色边框并带生命条。胜利结算依次显示挑战目标与「下一步」、获得道具与「下一步」，再回地图；第1回合三星后，地图累计星数为3且第2回合解锁。

右下「报酬」打开「★获得任务」，本期累计奖励从3星至54星，每3星一档，共18档；未达成的「收取」及「全部收取」灰显。列表可滚动，超出持有上限的道具送礼物箱，「取消」回地图。**国服实测（2026-10-11，3星报酬）**：领奖回执标题「收取报酬」，正文「获得了以下报酬。」，底部「关闭」返回列表。已领取行移到未领取行之后，背景灰显，左侧显示「已完成」印章与3/3，右侧不再显示收取按钮；因此54星档不一定是列表最后一行。

**国服实测（2026-10-11，右上「玩法」）**：可可萝说明胜利解锁下一回合、战斗效果触发技能或提升属性、达成挑战目标获得星并领取任务报酬。说明示例图中的5/18、12/54不是账号当前进度。

**官方资料（台服，同类回合制玩法，2026-09-30）**：[战斗试炼场公告](https://www.princessconnect.so-net.tw/news/newsDetail/4063)说明全程自动、满生命值和零技能值开场，挑战不消耗体力或挑战权，可重复挑战。回合逐步开放，首通与累计星级奖励分别计算，领奖期限晚于挑战期。国服开放时点及结束后页面以当前游戏为准。

**使用者提供（2026-10-11）**：每期完成一次以取得全部奖励。结合三星任务，完整目标需要核对累计星数及奖励收取状态。
