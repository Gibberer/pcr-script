# 斗技场

适用：国服雷电 960×540。回合制斗技场与常驻「竞技场」「公主竞技场」不同。依据为 **国服实测（2026-10-11～12，本期 10/09 12:00～10/13 23:59）**，另注者除外。

## 页面与流程

首页 → 冒险 → 左下圆形「斗技场」。地图顶栏显示「回合 N/总数 解锁」与「★ 已得/总数 获得」；本期共18回合、54星，开始时解锁1回合、0星。每页三个回合，左右箭头翻页；卡片底部有三个星级槽，金星为已达成、蓝星为未达成，下方为首通报酬。

回合卡片打开「编组详情」：敌方五人及等级、挑战目标、战斗效果、初次通关报酬。「挑战」进入未开战的「队伍编组」，「战斗开始」才提交；取消编队回详情，再取消回地图。编队上方为对手信息，筛选栏在其下，列表下拉到顶后出现搜索栏，选中成员在底部五槽。可只派一至四人，其余槽留空。

战斗全程自动，头像为金色边框并带生命条。胜利结算依次显示挑战目标与「下一步」、获得道具与「下一步」后回地图；败北页显示「LOSE」「再次挑战」及「下一步」，「下一步」回地图，星数与解锁不变。

## 星级与解锁

每回合三个挑战目标各给一星，类型为：剩余时间不少于某值获胜、我方总生命值不少于某百分比获胜、无法战斗的角色不超过某人数获胜。胜利即解锁下一回合，与得星数无关；未满星的回合可重复挑战补星。挑战不消耗体力或次数。

## 累计报酬

右下「报酬」打开「★获得任务」：3星至54星每3星一档，共18档，可滚动；未达成档的「收取」及「全部收取」灰显，超出持有上限的道具送礼物箱，「取消」回地图。领奖回执标题「收取报酬」、正文「获得了以下报酬。」，「关闭」回列表。已领取行移到未领取行之后，灰底并显示「已完成」印章与 N/N，不再有收取按钮，因此54星档不一定在最后一行。全部54星后，地图进度条显示「COMPLETE!」，右上「未达成」不再显示数字。

右上「玩法」说明胜利解锁下一回合、战斗效果触发技能或提升属性、达成目标得星并领取任务报酬；示例图中的进度数字不是账号进度。
