## 扫荡（实测）

- 系统“一键扫荡”先进入“关卡一览”；清除所有勾选后每批只选一个已通过关卡。H 每次 20 体力，每日每关 3 次，N 每次 10。
- 第一次“一键扫荡”打开“一键扫荡确认”；需再次核对唯一关卡及总消耗，再点“挑战”。此按钮直接消耗体力。
- 次数框的孤立数字“1”也可能被全屏 OCR 漏掉，单纯放大仍可能被文字检测器过滤。数值框先做局部检测识别；未检测到文字时再直接识别整框（`use_det=False, use_cls=False`）。数字 0 需要保留检测裁边才能达到足够置信度；不能用缺字或低置信结果猜测数值。
- 结果可能很快返回“关卡一览”，未必能捕获独立结果页。必须核对剩余次数减少（或普通关卡体力减少）后再判断成功；不确定时不能再次点击消耗。
- 确认按钮关闭后先出现灰色“正在进行数据连接”的旧列表，此时旧次数尚未更新，需等待连接结束再核对。当前实际还会出现“扫荡结果”弹窗，确认后才返回有新次数的列表；可从结果弹窗恢复核验，不重复发起消费。
- 体力不足记录未完成并继续后续领奖；不购买体力、不重置次数。
- 2026-09-12 重复日复测：空选择时点击“解除所有勾选”会出现“未勾选任何关卡”提示，遮住 H-2 的剩余次数。必须等提示消失再读数，不能直接报未知或猜次数。
- 扫荡确认标题的“一”偶尔被 OCR 漏掉，读成“键扫荡确认”；兼容这一已实测变体，同时继续强制核对唯一关卡及总体力。中断留在此确认页时，入口先取消原计划并重读进度，不能直接确认旧消费。

## 任务、兑换、剧情（实测）

- 活动任务有“每日、普通、特别、称号”四栏。“全部收取”亮蓝可用，暗蓝禁用。扫荡及读剧情后检查四栏。
- 兑换页原生“一键交换”直接消耗显示的全部券数，并自动处理奖池重置；用消耗数与余额一致性检查，交换后核对余额归零。
- 全屏 OCR 会漏识别孤立的数字 0，可对已知余额框放大 OCR；缺失不能视为零。
- 体力降到个位数会被全屏检测漏掉（2026-09-12 实测数字 4）。用户明确要求：**体力数值不是硬性条件，不能因读不出体力阻断主流程**。仅用一次全屏读数优化批量次数；读不到时设为一次，用游戏“体力不足”提示/按钮可用性决定停止扫荡并继续领奖。困难结算核对剩余次数；普通结算可用实际结果弹窗，无数值且未见结果时停止追加扫荡并继续领奖。
- 主剧情有语音选择、菜单跳过、梗概确认、动画隐藏跳过热点、奖励确认等分支。动画下载期间有整体超时，不应把加载画面当作新的按钮。
- 本期“复制世界回忆录”是独立额外剧情：艾拉世界横向节点、诗夏世界纵向节点，通过 NEW 逐个打开。根页终章没有 NEW，而是右上角宝石“×30”，外观类似锁；本期点击后实际可读。其他活动的小游戏不能假设共用此流程。
