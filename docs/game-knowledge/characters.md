# 角色、编队与养成

本页记录游戏中的角色信息。国服证据来自雷电 960×540；各节注明观察日期与范围，跨服资料单独标注。

## 角色如何分类

| 维度 | 含义与核对方式 |
|---|---|
| 身份与衣装 | 同名不同衣装是不同角色；详情可能只显示基础名，须结合头像、完整碎片名称或技能确认。 |
| 站位 | 前卫、中卫、后卫影响排列与承伤位置；参考角色资料和[Cygames 角色列表](https://gacha.priconne-redive.jp/gacha_information/index/rXvmgz)。 |
| 攻击方式 | 物理／魔法决定主要攻防属性的意义，见[Cygames 帮助](https://dmg.priconne-redive.jp/help/)。 |
| 战斗属性 | 火、水、风、光、暗；国服深域按五属性分区。通用弱点规则见[日服更新说明](https://dmg.priconne-redive.jp/news/detail.php?id=26078)。 |
| 职能 | 攻击、破防、增益、减益、加速／TP、治疗、坦克、干扰；[八种职能说明](https://priconne-redive.jp/news/update/30614/)为日服资料，国服名称与角色归属以当前页面为准。 |

## 强度与配队

战力不能单独证明队伍可用。等级、技能、Rank、星数、专武 1/2、特别装备、好感度剧情和全局强化均影响属性；输出还取决于目标防御、弱点、站位、技能与队友。攻略指定低 Rank、星数或 SET 时，更高数值不一定等价。[官方帮助](https://dmg.priconne-redive.jp/help/)说明 Rank 也影响受击 TP 回复。逐项检查见[配队与战前检查](party-building.md)。

人物页的一键强化先预览角色和资源，再确认消费；自动强化、品级提升、才能开花和两类装备是独立操作，允许其中一项不代表允许其他培养。

## 普通装备与专武

**国服实测：2026-10-03～05。**

| 页面 | 可核对的事实 |
|---|---|
| 普通装备 | 点选槽位后四角出现白框，右侧显示该槽说明。未来槽为问号，文案“这件装备预定今后登场。”；已穿戴且强化完成显示“这件装备的强化阶段已达极限。”。开放、穿戴、名称及强化是不同状态。 |
| Rank 38 示例 | 美杜莎、惠理子（教官）、格蕾丝、克莉丝提娜（阿尔法）、薇奥莉特有四个开放槽和两个未来槽；四件已装备不等于缺两件，其他角色／Rank 另行核对。 |
| 专武独立槽 | 夏日佩可莉姆页左上两图标分别切换装备名称、属性和强化技能；最右大箭头切换角色。只显示一个图标不能推断专武2状态。 |
| 专武1数值 | 图标下为等级，右上“强化Lv上限”为已解放上限，左下人物等级是另一数值。 |
| 专武2满强化 | “此专用装备2已强化至最强。”与装备下五颗金星共同确认，不能套用专武1等级。 |
| 尚未实装 | 人物页明确的预定登场文案可确认对应槽未开放；已观察银莲、雪菲（公主）、妮侬（夏日）及菈比莉斯塔（阿尔法）的专武1。编队仅未出现徽标不足以确认。 |
| 编队徽标 | 头像左下轮播星数与专武1、专武1＋2徽标；只有未遮挡的有效信息帧才可判断。战斗中的星星／增益图案不沿用此规则。 |

## 公主骑士强化与职能精通

**国服实测：2026-10-05，公主骑士强化、职能节点、精通扭蛋及强化任务。**

底部“强化”进入公主骑士强化；顶部为属性等级、属性技能、大师技能、职能精通。八个职能图标切换节点。Lv、卡片金星、精通扭蛋等级及大师道具持有量含义不同，不能互相代替。属性详情分别显示五属性的攻击力、百分比加成和技能值上升。

| 操作 | 页面与资源规则 |
|---|---|
| 节点强化／升级 | 右侧显示当前属性、下次增量、所需材料及持有数；不足时按钮禁用。同等级强化至五星后才出现“升级”，下一次提交改变 Lv；两者均经“强化确认”，之后分别核对等级和属性。已观察增益型生命节点 Lv2→Lv3。 |
| 材料转换 | 确认页显示材料图标及本次消耗，节点页显示库存；三个低一级同类材料可折算一个所需等级材料，以当次预览为准。同类库存与可转换材料由节点共享，全能精通还区分等级。 |
| 精通抽取 | 抽取页显示扭蛋等级、进度及券余额；单抽标示耗1张，批量通常耗500张，余额不足时按按钮显示的持有量抽取，已观察150张。批量直接消费，无提交前确认；抽取不会直接强化节点。 |
| 抽取结果 | “取消”返回抽取首页，“再次抽取”再消费；券为零时只显示“确认”退出。文字和余额可延迟稳定，首页也可核对券余额。 |
| 强化任务 | 右上“任务”进入列表；已达标行为“收取”，未达标为“挑战”。“全部收取”领取现有奖励，无奖励时灰显；回执为“收取报酬”“收取了以下道具。”，可含带等级的全能材料。关闭回列表，左上返回职能精通。 |

## 星级与记忆碎片

**国服实测：2026-09-24～28，逐星1→5、女神秘石商店及已解锁星级变更。**

才能开花确认页显示当前／目标星数、玛那和碎片消耗，完成后回人物页核对已解锁星数；每一星重新读消耗。碎片购买回执分别显示碎片和秘石余额的前后变化，零持有量也会显示；MAX 不等于缺额，末批可调数量。购买只证明到账，开花仍须独立确认。价格见[商店](shop-quests.md)。

商店搜索可同时返回多衣装，须核对完整名称。“购买完毕”标题可能先于正文稳定；数量、价格等短数字须按各自区域核对。已解锁五星可设置为较低星级；“★变更确认”的“现在的★”标记随当前星级移动，不能用固定列判断。星级变更不购买碎片。

## 好感度与角色剧情

好感度可按从低到高排序，赠礼预览显示完整衣装与消耗。“剧情解锁”不等于首读奖励到账，须进入剧情并结算；国服已见宝石与攻击力奖励，[官方帮助](https://dmg.priconne-redive.jp/help/)也说明部分首读增加属性。

**国服实测：2026-10-04，美杜莎与薇奥莉特剧情。** 可读卡为白底和角色头像，头像金色装饰不是锁；锁定卡为灰底、问号头像及金色心形锁，点击才显示实际条件。薇奥莉特好感度8后的第一话仍要求主线第3部第12章第6话，不能由好感度推断前置剧情已满足。其他角色另查条件。

## 编队与身份界面（国服实测）

**证据范围：2026-09-24～10-04，光深域、剧情活动、深渊讨伐及追忆战编队。**

- 搜索栏可能须滚到顶部才出现，基础名字可返回多衣装或完整双人名。重置、聚焦、安卓输入条提交及选人后清空均可能延迟；须核对游戏搜索框和更新后的结果卡，输入成功或旧卡片位置不能证明持有与身份。
- 五槽在移除成员后重新排列。长按头像可读等级、Rank、星数和技能；详情可能省略衣装。技能正文可能延迟，长连结爆发说明会将普通技能推到下方，列表还可能保留滚动位置。
- 离开未开战编队去人物页后，返回可恢复先前保存的队伍；刚选入五人不代表已保存，须重新核对。
- 才能开花的碎片名称可确认衣装；六星角色可能默认显示“角色（衣装）的纯净记忆碎片”，没有普通碎片标题不代表衣装错误。
- 米洛克第1层倒下头像仍有颜色但变暗，生命条清空；开场暗幕中的存活头像也可能暗，但保留绿色生命条。闪光遮挡时不能由未见暗头像推断全员存活。
