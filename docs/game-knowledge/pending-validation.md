# 等待特定状态的验证

状态更新时保留实测日期与证据。以下项目不能因为离线测试通过就标记实战通过。

| 项目 | 触发条件 | 验收步骤 | 当前状态 |
|---|---|---|---|
| 新版活动首日过图 | 下一次有未通过的 N/H 关卡 | 从 N-1 依次推进、处理解锁剧情、核对实际星数；失败有限次停止 | 推断实现，账号已全通无法验证 |
| 剧本模式首通 | 剧本首领未通过 | 验证固定支援/编队、战斗设定、结算后通关标记 | 未实战验证 |
| SP/SP＋通关 | 对应难度未通过且存在达标队 | 核验三个开关与 SET，验证减员撤退、换队、模式切换、剩余次数和最终通关 | 2026-09-12 SP＋模式1五人配队审查通过；实战尚未验证 |
| SET 全局设置 | 首次进入可测试战斗 | 确认游戏已启用 UB 即发动模式，逐人点击后复核 SET 状态；不符则撤退 | 游戏[官方说明](https://dmg.priconne-redive.jp/news/detail.php?id=17506)要求先启用全局开关，当前账号实战待验 |
| 本体怜替换作业 | 获取明确专武 2 状态的攻略 | 将 `config/event_teams.yml` 中本体怜的 `unique2: null` 补为有来源的实际要求 | 来源未明确，候选会被阻止开战 |
| SP＋失败保留进度 | 一次战斗未打完模式 | 区分伤害结算与失败，核对进度变化；不得重置整场 | 待实战验证 |
| 旧版复刻 | 复刻旧地图开启 | 保存入口、N/H 地图、每日高难首领；单独适配，禁止套新版坐标 | 本次未适配 |
| 无活动 | 冒险页无活动入口 | 多帧确认后跳过，日常其他项目继续 | 仅离线模拟 |
| 剑徽混色的直接核验 | 可进入已开专武 2 角色人物页 | 将人物页两件实际装备与混色剑徽对应，新增截图回归 | 2026-09-12 已完成，本体怜两件装备与混色剑徽一致 |
| 衣装过多的搜索结果 | 同基础名超过一屏 | 分页定位目标，正确处理未拥有/未识别 | 当前搜索角色最多六个结果 |

所有活动重复运行还应检查：不重打已通关首领、不重复消费、不漏活动任务、不把零和未知混淆。日常步骤已通但体力不足时，应报告部分完成及剩余原因。
