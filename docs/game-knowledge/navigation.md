# 界面地图

适用：国服雷电 960×540；2026-09 实测。入口名称、活动布局可能变动。

| 起点 | 路径 | 识别要点 |
|---|---|---|
| 首页 | 冒险 → 剧情活动 | 本期列表式；首页有“关卡·首领”、剧情、任务、兑换。 |
| 首页 | 冒险 → 复刻 | 本期地图式；复刻身份不保证地图布局。 |
| 首页 | 冒险 → 特别关卡 → 地下城 | 难度卡片 → 区域确认 → 楼层地图。 |
| 首页 | 冒险 → 深域关卡 | 五属性区域 → 属性地图；地图顶部可切属性。 |
| 首页 | 冒险 → 驾车游 | 赛季地图、骰子、回合、检查点。 |
| 首页 | 冒险 → 团队战 | 五个首领位置、各自轮次与剩余挑战次数；见[团队战](team-battle.md)。 |
| 首页 | 角色 → 角色一览 → 人物页 | 角色身份、培养、专武、才能开花。 |
| 首页 | 商店 | 顶部标签含通常、特别装备、限定等。 |
| 首页 | 礼物 | 礼物箱；满仓会显示持有上限。 |
| 首页 | 任务 | 每日、普通、称号三个标签。 |

易混淆：冒险菜单的“主线关卡”卡片与主线地图标题同名。弹窗、教程、剧情和数据连接遮罩可覆盖当前页面；待覆盖层消失后判断所在页。

**国服实测（2026-09-24，雷电 960×540）**：主线关卡快捷扫荡选中剩余挑战次数为 0 的关卡时，会弹出「一键回复挑战次数」。点「不回复，进行下一步」可跳过宝石回复，随后进入扫荡确认；若使用券张数超过部分关卡剩余挑战次数，最终确认页提示无法扫荡。调低使用券张数后，可正常显示扫荡结果。
