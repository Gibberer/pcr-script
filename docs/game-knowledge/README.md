# 游戏知识

这里记录游戏中的页面、角色和玩法，不记录脚本设计、测试结果或开发经过。先从[界面地图](navigation.md)定位入口，再阅读对应玩法。页面会随版本和活动变化，国服观察范围与跨服资料应明确区分。

| 主题 | 内容 |
|---|---|
| [界面地图](navigation.md) | 首页、冒险、角色、商店、任务等入口的关系 |
| [角色、编队与养成](characters.md) | 角色身份与衣装、站位、职能、属性、培养和战斗状态 |
| [剧情活动](story-events.md) | 列表式活动、关卡、首领、扫荡和领奖 |
| [复刻活动](revival-events.md) | 地图式活动、自动推进、首领和讨伐证 |
| [地下城](dungeons.md) | 区域、楼层、队伍占用、首领进度 |
| [深域关卡](abyss.md) | 五属性地图、挑战次数、关卡与编队 |
| [驾车游](caravan.md) | 骰子、检查点、格子事件和结算 |
| [团队战](team-battle.md) | 五首领轮次、挑战次数、推荐编组和模拟战 |
| [礼物与特别装备](gifts.md) | 礼物箱、持有上限与特别装备 |
| [商店与任务](shop-quests.md) | 商店标签、购买界面、任务奖励 |
| [待观察的游戏状态](pending-validation.md) | 自然出现时需要核实的页面或规则 |

一条知识应先写当前结论，再标注依据：**国服实测**（日期、页面或活动；原始证据留在本地忽略目录）、**官方资料**（链接及服区）、或**待验证推断**。活动特有机制不要写成通用规则；同一事实只在所属专题维护。截图与账号数据保存在本地忽略目录，不提交仓库。

任务如何执行、识别边界和开发说明见[文档索引](../README.md)。
