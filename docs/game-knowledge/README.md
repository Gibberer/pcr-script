# 游戏与界面知识

此目录用于跨活动保留事实、排查线索和等待特定游戏状态的验证任务。账号截图和 OCR 原文保存在忽略的 `cache/`，这里仅记录机制和复现方法。

Windows 前台控制终端及离线验证说明见 [GUI 文档](../desktop.md)。GUI 不新增游戏规则；本次未操作模拟器，真实运行验证继续按待验证记录接续。

**2026-09-19 用户纠正的实现边界：** Agent 操作只用于分析验证。头像获取/更新与当期队伍方案获取/生成必须纳入正式自动化，不得依赖 Agent 手工准备。真实配置和方案不提交；本地缓存可跑通不等于空缓存端到端完成。当前这两条自动获取链路尚未接通，见待验证表中的“待实现”项与 `AGENTS.md`。
