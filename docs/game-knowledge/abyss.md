# 深域关卡

适用：国服雷电 960×540；2026-09-22～25 实测。入口见[界面地图](navigation.md)。以下仅概括观察范围，不把单次战果推广为通用消耗规则。

## 地图与进度

- 五区：红焰=火、苍波=水、翠岚=风、珀天=光、紫冥=暗。区域页显示各属性剩余挑战次数，地图顶部可切区。
- 黄色 NEXT 指向当前可推进关卡。地图自动平移，NEXT 可能被属性栏挡住；结合附近唯一编号与详情标题确认。锁定关卡也有编号，不能按编号大小猜进度。
- 详情显示区域/关卡、体力、次数及“公主骑士品级”；后者不是角色装备 Rank。次数为零时不能继续；体力不足会弹回复确认，已有家具体力可从[公会之家](guild-house.md)领取后重新核对。

## 战后可见状态

| 状态 | 国服实测与边界 |
|---|---|
| 胜利推进 | 已观察胜场的 NEXT 前进且次数减一；章节末关胜利后进入下一章。 |
| 失败不推进 | 火 5-6 等已观察失败场次的 NEXT 与次数未变；不能据此推断所有关卡或体力消耗。 |
| 撤退 | 水 5-3 从战斗菜单撤退后 NEXT 与次数未变；其他撤退状态仍待观察。 |
| 剧情与弹窗 | 水 3-7 战后出现角色剧情，跳过后 NEXT 为 3-8；光 3-5 战后出现团队战 CP/挑战次数提示。遮挡期间不能仅凭等待时间判断战果。 |
| NEXT 遮挡 | 风 3-5 胜利后 NEXT 字样被属性栏遮住，编号 3-6 与次数仍可见；需结合详情核对。 |
| 次数耗尽 | 地图显示剩余 0/10，详情显示今日次数为零。 |

WIN 后还可能出现首通奖励或限定商店；失败页可“前往深域关卡”回地图。先处理覆盖层，再核对关卡与次数。无 NEXT 的终点状态、其他失败/撤退的资源规则见[待观察清单](pending-validation.md)。

## 编队相关

- 编队五槽；特别装备每人三槽，灰色轮廓为空。自动装备可能从其他角色调装备，预览与“装备确定”分开。
- 人物页 3 金星＋2 蓝星可表示当前 3 星、已解锁 5 星；已实测“★变更”切回 5 星不消耗碎片，与才能开花不同。
- 保存队伍仅代表当前阵容，不证明符合攻略；身份、专武和战斗状态见[角色](characters.md)。
