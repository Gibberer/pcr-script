- 五区：红焰=火、苍波=水、翠岚=风、珀天=光、紫冥=暗。区域页显示各属性剩余挑战次数；地图顶部可切区。
- 黄色 NEXT 指向当前可推进关卡。地图自动平移，NEXT 文字可能被属性栏挡住；附近唯一编号和详情标题共同确认关卡。锁定关卡也显示编号，不能按编号大小猜进度。

- WIN 后可有首通奖励、NEXT 前进及限定商店弹窗。失败页可“前往深域关卡”回地图。失败后重试可能成功；具体次数/体力变化按当场页面核对，不推广单次观察。
