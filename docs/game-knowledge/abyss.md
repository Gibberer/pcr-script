# 深域关卡

适用：国服雷电 960×540；2026-09-22～23 实测。入口见[界面地图](navigation.md)。

## 地图

- 五区：红焰=火、苍波=水、翠岚=风、珀天=光、紫冥=暗。区域页显示各属性剩余挑战次数；地图顶部可切区。
- 黄色 NEXT 指向当前可推进关卡。地图自动平移，NEXT 文字可能被属性栏挡住；附近唯一编号和详情标题共同确认关卡。锁定关卡也显示编号，不能按编号大小猜进度。
- 详情显示区域/关卡、体力、次数及“公主骑士品级”；后者不是角色装备 Rank。次数 0 时不可继续；体力不足会弹出回复确认。
- WIN 后可有首通奖励、NEXT 前进及限定商店弹窗。失败页可“前往深域关卡”回地图。失败后重试可能成功；具体次数/体力变化按当场页面核对，不推广单次观察。

## 编队相关

- 编队五槽。特别装备页对应五人，每人三槽；灰色轮廓为空槽。自动装备可能从其他角色取装备；预览与“装备确定”分开。
- 人物页 3 金星＋2 蓝星可表示当前 3 星、已解锁 5 星；实测“★变更”切回 5 星无碎片消费。此操作不同于消耗碎片的才能开花。
- 保存队伍只表示游戏当前阵容，不证明符合攻略。角色身份、专武及战斗状态见[角色](characters.md)。

未知：无 NEXT 的终点状态；不同关卡失败/撤退的资源规则；其他分辨率。
