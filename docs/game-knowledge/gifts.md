# 礼物与特别装备

适用：国服雷电模拟器 960×540；2026-09-12 实测。

## 礼物箱

- 首页礼物入口。全部收取按批处理，实测每批最多 100 件。
- “除体力外确认收取”蓝勾表示本批排除体力。确认弹窗与成功结果都可能叫“收取礼物”；以正文区分。
- “持有上限”只说明某类道具已满，不能直接判定是特别装备。曾有家具留在礼物箱、特别装备库存未满的状态。

## 特别装备

- 商店“特别装备”标签下可进入分解与道具一览。实测持有上限 5000。
- “一键分解”“自动分解”“自动分解设定”是不同入口。自动分解使用游戏内当前保存的设置；实测一批选择 50 件，结果后库存减少 50。回收货币数不等于装备件数。
- 编队“特别装备设定”用于装备分配，与分解不同。自动装备可能取其他角色装备。
- **国服实测（2026-10-02）**：编队进入后，页首为“特别装备设定”和“可变更队伍角色的特别装备。”；底部有“取消”“自动装备”“装备确定”。五名成员各有三槽，自动装备后的选择仍须“装备确定”提交，返回编队再核对。
- **国服实测（2026-10-05，自动特别装备设定）**：全部、武器、防具、饰品各有“优先属性值”选择器。防具选择器的弹窗包含稀有度、有技能、物理／魔法攻击力、物理／魔法防御力、生命值、物理／魔法暴击及物理／魔法防御贯穿；已选项的圆钮中心呈蓝色。勾选“选择其他角色装备中的特别装备”可取用其他角色的现有装备；优先属性设置和预览并不替代最后的“装备确定”。

未知：非特别装备满仓且无可分解物时的状态；其他版本上限及批量数。
