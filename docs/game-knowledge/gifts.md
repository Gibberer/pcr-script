# 礼物与特别装备

适用：国服雷电 960×540；2026-09-12 实测。

## 礼物箱

- 首页礼物入口。全部收取按批处理，实测每批最多 100 件。
- “除体力外确认收取”蓝勾表示本批排除体力。确认弹窗与成功结果都可能叫“收取礼物”；以正文区分。
- “持有上限”只说明某类道具已满，不能直接判定是特别装备。曾有家具留在礼物箱、特别装备库存未满的状态。

## 特别装备

- 商店“特别装备”标签下可进入分解与道具一览。实测持有上限 5000。
- “一键分解”“自动分解”“自动分解设定”是不同入口。自动分解使用游戏内当前保存的设置；实测一批选择 50 件，结果后库存减少 50。回收货币数不等于装备件数。
- 编队“特别装备设定”用于装备分配，与分解不同。自动装备可能取其他角色装备。

未知：非特别装备满仓且无可分解物时的状态；其他版本上限及批量数。
