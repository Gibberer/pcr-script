# 复刻剧情活动

适用：国服 2026-09 地图式复刻，雷电 960×540。冒险页“复刻”与“剧情活动”是不同入口；复刻身份不保证地图布局。

## 地图与战斗

- 本期普通 1-1～1-10、困难 1-1～1-5。地图横向移动，黄色“下一关”标记提示待通关节点；以详情标题和星数核对。
- 关卡详情可开自动推进。最终关之后依次可能出现自动推进结束、最终关结算、报酬一览；第一个胜利画面不是完整结算。
- 本期普通首领耗 20 券，困难首领耗 30 券；高难和 SP 有独立模式。SP 通关后“表演赛”为练习入口。券数与首领机制仅适用本期。
- 战斗中 AUTO 与个人 SET 独立。个人 SET 在国服表现为头像蓝色圆标，动画可能遮挡；暂停菜单中可分别观察五人。菜单“SET关闭”不能证明全员都关闭。

## 剧情与兑换

- 地图首页有活动剧情、活动任务、讨伐证交换。本期“水都的回忆”为纵向列表，首屏外可有未读章节；完整阅读后可出现称号结算。
- 活动任务分每日、普通、特别、称号四栏。剧情和兑换后可能新增可领项。
- 讨伐证抽奖单次最多选择 100 张，实际次数受余额和本轮剩余奖励限制。抽空后的“重置”是换奖池，非重置首领进度。交换可直接消耗券数，无额外购买确认。
- 未读到券余额不等于零；结算时不依赖背景旧数值。

验证边界：本期地图、普通/困难、高难、SP、剧情和兑换均有实测；未来列表式复刻及新期完整首通待观察。
