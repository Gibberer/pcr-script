# 角色好感度与剧情解锁

按需任务 `max_character_bonds`，配置段 `CharacterBond`。使用现有礼物将持有角色好感度尽量提升到游戏当前允许的上限，然后逐篇跳过新开放的角色剧情，核对首读报酬和属性值提升回执。不购买礼物，不改变星级、专武或普通装备。

```powershell
./.venv/Scripts/python.exe -X utf8 scripts/daily/task.py max_character_bonds
```

任务从首页进入角色一览，设置“好感度”从低到高排序。对每位角色先在“好感度剧情→好感度提升”中点“最大强化”，核对赠礼预览的角色衣装、前后品级、每种礼物消耗和可用按钮；满级提示直接跳过。确认赠礼前先归档待结算记录，结果通过“剧情解锁”弹窗确认。随后在该角色的剧情列表找“新内容”，以无语音模式进入，从菜单“跳过”并二次确认，核对报酬弹窗。新剧情可连续自动提示，任务对每一篇分别留证。

本轮角色数量、列表翻页、每名角色的剧情步骤、礼物总件数和整场时间都有上限；达到上限或识别未知页面时报告 `partial`，不宣称所有角色完成。报告位于 `cache/daily/runs/<run>/tasks/001-max_character_bonds/report.json`，包括礼物预览及结果、逐篇奖励和待处理项。角色排序可能因好感度提升改变，任务会重新检查当前格位；礼物不足时保留未完成项。可按需调低 `max_characters` 做小批试运行。

如果需要接续某位角色的未读剧情，可在本次 `CharacterBond` 配置中临时设置 `focus_character: 七七香(万圣节)`。任务通过人物搜索和记忆碎片名称核对完整衣装，只处理指定角色；完成后删除该临时选项，恢复全角色遍历。

实机页面、验证边界见 [角色知识](game-knowledge/characters.md) 和 [待验证记录](game-knowledge/pending-validation.md)。
