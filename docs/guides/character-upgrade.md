# 强化所有角色装备和等级到上限

GUI 单项任务选择同名任务，或在工程根目录运行：

```powershell
./.venv/Scripts/python.exe -X utf8 scripts/daily/task.py upgrade_all_characters
```

正式注册名为 `upgrade_all_characters`，按需使用，不自动加入日常。直接运行即会使用账号现有强化资源。

任务进入角色一览的一键强化，先选择游戏当前最高可用品级，再启用等级／技能等级、佩戴普通装备、消耗原矿和最大限度强化装备。游戏将等级与技能合并为一个选项。每批自动选择最多20名，核对确认页和完成页后继续；免费强化结束但仍可继续的角色会再次被选中。

不进行等级突破、才能开花、专武或特别装备强化，也不购买资源。上限指当前账号已开放且游戏此入口允许的上限。未知弹窗、无法识别的数量、资源不足、确认不可用或超时均保留现场并返回 partial，不把停止写成完成。两个模式均自动选择为空且确认不可用时返回 complete；这不代表未实装装备已经开放。

可选配置：

```yaml
CharacterUpgrade:
  timeout: 1800
  max_batches: 40
```

证据和报告由正式 RunSession 存入 `cache/daily/runs/<run>/tasks/.../`。目前实机布局为960×540；坐标按截图尺寸换算，其他布局仍待验证。
