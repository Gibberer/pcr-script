# 斗技场：本期满星与领奖

`battle_stadium` 以本期回合全部三星、累计报酬全部领取为目标。GUI 在按需专项中选择，CLI 使用：

```powershell
./.venv/Scripts/python.exe -X utf8 scripts/daily/task.py battle_stadium --config daily_config.yml
```

每次运行先从游戏读取实际星数与报酬状态：满星且全部领取时直接返回 `already_complete`，不进入任何回合；满星但仍有报酬时只领奖。活动情报包含挑战期及之后的领奖期，领奖期只领取已有报酬。默认不在完整日常列表中，需要自动接续时可添加 `[battle_stadium]`。挑战不消耗体力或次数；任务不培养角色、安装或强化专武、购买资源、回复次数或重置进度。

## 配置

GUI 与 CLI 共用根目录 `runtime_defaults.yml` 的 `BattleStadium` 段：

| 选项 | 默认 | 含义 |
|---|---|---|
| `max_battles` | 36 | 本次合计挑战上限 |
| `max_attempts_per_round` | 2 | 本次每回合最多实战方案数 |
| `timeout` / `battle_timeout` | 7200 / 180 秒 | 任务及单场等待上限 |
| `claim_rewards` | `true` | 领取累计报酬；关闭时不报告全奖励完成 |
| `discover_sources` | `true` | 自动搜索本期攻略 |
| `source_urls` | `[]` | 本任务优先视频链接 |
| `allow_local_trials` | `true` | 来源出战成员明确但培养不完整时，核验当前账号后有限试打 |
| `auto_equip` / `auto_equip_priorities` | `false` / `{}` | 核验队伍后按游戏自动设定重新分配现有特别装备，可指定优先属性 |
| `account_key` | `default` | 账号恢复隔离键，切换账号需使用不同键 |
| `sources` | `{}` | 共用视频解析及公共头像选项，如 `max_videos`、`max_frames_per_page`、`search_queries` |
| `sources.refresh_media` | `false` | 重新取得视频并解析，排查完成后关闭 |

`auto_equip_priorities` 例如 `{armor: hp, accessory: hp}`，支持值与[追忆战指南](recollection.md)相同。它只重新分配已有装备，无变化时取消预览，不能代替来源指定装备的核验。

## 攻略来源

程序自动搜索、下载并解析本期攻略，不需要 Agent 预先准备队伍文件。来源须属于本期、确认国服与具体回合，全部出战成员在至少两帧一致识别；支持一至五人队伍，少于五人时须确认其余槽为空，且实际战斗成员与最终编队一致。作者补充未完整读取、存在未支持的培养／装备全局条件或手动操作时不采用。识别细节见[视频解析](../video-strategies.md#斗技场)。

斗技场来源默认每分P最多解析600帧并覆盖整段合集；每回合共用 `sources.max_videos`（默认4个）预算，元数据或解析失败也计入。有连续胜利结算证据的方案优先，只有败北证据的方案不试打。

## 战前核验

搜索结果的公开头像已确认完整衣装时，只读人物详情的等级、Rank、星级与专武，不进入技能页；头像无法确认身份，或来源声明了技能等级时才读取技能。搜索输入无法确认时改为扫描完整角色列表，仍按同样规则核验。编队徽标不能明确专武状态时，用人物页只读核对，再回到目标回合重新选人；仍未知则停止。`allow_local_trials` 不表示复现原攻略：身份、等级、Rank、星级、专武及特别装备仍须核验，来源已声明的要求不能绕过。

## 重试、恢复与结果

优先处理已解锁但未得星的回合，再回到已胜利的回合补星。某回合缺可用方案时记录原因并继续其他回合；全部处理后仍有缺口返回 `partial`，后续回合未解锁时同样返回 `partial`，解锁后重跑接续。

战后重读回合星级，不以胜利动画或进程退出表示完成。未满星的队伍按回合、等级、Rank、星级、专武与实际特装记录，条件不变时不重复试打；重跑优先尝试本期该回合未试过的成员组合，显式更改优先属性只触发复核。

开战与领奖前保存待核对记录。重跑先回到斗技场地图核对上次结果：星数增加即确认；没有结算画面且星数未变时，因挑战不消耗资源，释放该记录且不计为失败。领奖只收取实际星数已达门槛的档，星数或回合总数读不清时停止；领奖记录须在列表中确认已领取才解除，未确认时不重复领取。人物核验或搜索中断后，重跑先关闭人物详情或安卓输入条，再退出未开战编队。

报告和证据在当前运行目录，账号恢复记录位于忽略的 `cache/game/battle_stadium/`。尚未验收的范围见[工程待办](../pending-validation.md)，游戏页面与目标见[斗技场](../game-knowledge/battle-stadium.md)。
