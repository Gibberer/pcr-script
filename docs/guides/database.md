# 本地数据库更新

GUI 和 CLI 自动从游戏资源服务器检查并更新任务所需静态资料，保存在 `cache/redive_cn.db`。正常运行无需开启 root，也不需要先启动游戏来刷新数据库。活动日程与角色静态资料使用同一来源，解析规则随项目维护。

默认六小时检查一次资源版本；本次运行的子任务复用同一缓存。数据库更新失败时保留旧文件，最多使用24小时内已验证的缓存，并显示提示。没有有效缓存或新版本结构无法识别时停止，更新项目后重试。

完整仓库还可单独运行更新命令，不需要设备配置：

```powershell
./.venv/Scripts/python.exe -X utf8 scripts/daily/update_database.py --force
```

`--force` 立即查询版本，版本相同不重新下载。`--offline` 只检查本地缓存，不联网；超过24小时的缓存不可用。`--output <路径>` 可更新一份独立数据库供检查，日常仍默认使用 `cache/redive_cn.db`。GUI 的“仅核心运行文件”没有这些 CLI 文件，但内部自动更新使用同一个模块。

命令会显示来源、版本、更新时间、主库校验值和缓存状态，不会登录账号或操作游戏。公共数据库只提供规则和定义，账号当前通关、剩余次数、券数及角色装备仍由任务在游戏中确认。

首次只读提取客户端主库可用于诊断或核对格式，但不是安装、更新或运行前提。关闭模拟器 root 不影响电脑端后续更新。工程细节见[任务前置静态资料](../masterdata.md)。
