# 本次 PR 审阅说明

本次改造让 GUI 和命令行通过统一 Python Task 实现执行任务；Agent 使用相同观察与运行证据进行分析、校准和复核。新增地下城首通、深域推进等专项，GUI 提供环境准备、日常配置、专项、运行控制与历史记录。

## 主要审阅点

1. **独立执行边界**：正式任务不能依赖先运行 Agent 探查或人工生成作业。公共头像自动获取和有限视频布局解析已接通，完整培养/辅助条件与多刀规划未完成；不能把已有缓存能运行写成从空缓存自动攻略完全完成。详见 [视频交接](video-strategies.md)。
2. **任务与数据边界**：游戏逻辑在 `pcrscript/tasks/`，共享识别在 `game_ui/`；GUI 只管理配置/进程/记录。实际头像、数据库、视频、队伍和账号配置留在忽略的 cache，不打包到 GUI。
3. **GUI 交互**：新增任务独立对话框；选中行只修改自身参数；无效值不静默丢弃；保存状态明确。专项不改日常配置；运行控制等待确认。
4. **文档与发布**：[README](../README.md) 以下载 GUI 为主，补 CLI；[GUI 图文指南](desktop.md) 与 [任务指南](tasks.md) 拆分。合并后按 [发布流程](releases.md) 创建版本标签，发布 ZIP 与校验值。
