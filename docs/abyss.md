# 深域关卡推进

正式任务 `abyss_push` 从冒险进入深域，按 `fire/water/wind/light/dark` 分别定位地图 NEXT。编队、战斗、结果、失败原因和截图写入统一 `cache/daily/runs/<运行>/tasks/<序号>-abyss_push/`。任务按需执行，不自动加入每日日常。

```powershell
./.venv/Scripts/python.exe -X utf8 scripts/daily/task.py abyss_push
```

在实际配置增加 `Abyss` 段，或在 GUI「按需专项 → 深域关卡 · 尽力推进」调整选项：

```yaml
Abyss:
  allow_local_trials: true
  source_urls: [] # 本深域任务的优先攻略链接
  audit_only: false
  elements: [fire, water, wind, light, dark]
  max_failures_per_stage: 6
  max_repeat_failures_per_stage: 2
  max_battles: 30
  timeout: 3600
  battle_timeout: 220
  discover_sources: true
```

本地试打需要明确启用 `allow_local_trials`，发布默认关闭。优先核验用户来源的适用队伍，缺失时检查属性保存队及有依据的替补。默认不强化角色；可另行启用本文的五星及秘石兑换开关，不购买体力或次数。来源有SET时采用来源设置，否则本地试验默认全员SET与AUTO；这不是源攻略的复现或最优队伍规划。首次探索每关最多6次失败，历史失败关卡后续运行最多补试2次；可用且有价值的阵容耗尽时提前换属性；单次战斗超时或减员通过战斗菜单撤退，全局次数和时间均有限制。未知弹窗停止并保留现场。

开战前读取角色身份、等级、Rank、星数和实时专武状态。头像可靠匹配时不翻技能页；身份不明时才按数据库的两项普通技能确认衣装。同一次任务内近期已核验的五人队伍先核对实时头像与专武徽章，匹配时复用人物详情；换队、升星或证据过期才重新打开人物页。未读取的技能等级保留未知，本地试打不设技能等级门槛。五人不齐或培养开关未知时，不猜测补员或跳过核验。每次非审查战斗前都会打开特别装备页执行一次游戏内「自动装备」，核对预览与提交后的装备槽位；游戏可能按默认勾选项从其他角色调配特别装备，不会自动强化或分解。尝试历史按 account_key 保存在 cache/game/strategies/abyss_history/，记录阵容、培养、截图、结果和重试依据；中断中的阵容也不当作从未尝试。多账号须配置不同 account_key。

以战后同一属性 NEXT 关卡前进为通关证据，不以胜利动画或战斗结算代替。无 NEXT 不直接等于全通。部分推进、次数用尽、失败达限都报告具体状态，不伪报全通。

## 通用攻略来源检索

`tasks/strategy_sources.py` 提供内部共享的来源获取器，输入 `task_type`、`area`、`aliases`、`stage`、`category_terms`、`region`，按这些维度隔离缓存，不在任务列表单独出现。地下城首通也通过同一共享来源流程查询，并使用自己的 `Dungeon.source_urls` 配置。深域自动根据已观察到的区域/关卡查询，缓存缺失或过期会刷新。

结果包含 BV、视频详情、分P、来源、获取时间、解析版本、服区及待核验项。仅明确排除相反服区；不明服区保留待核验。视频候选始终是 `source_only`，不能直接用于开战。2026-09-23 已增加自动公共头像建库、目标战斗分 P 和练度表的有限解析，输出逐字段证据；完整且适用的来源进入严格核验，不再使用账号当前状态覆盖源要求。支持 `Abyss.prepare_only` 只解析而不操作游戏，范围和剩余限制见[视频解析与 Agent 复核](video-strategies.md)。

搜索默认启用隔离浏览器会话：先加载本地有效Cookie走HTTP接口；接口要求站点验证时，每个检索器最多2次用 Playwright headless 正常访问搜索页并提取公开结果。默认复用系统Edge（`browser_channel: msedge`），不读取用户浏览器配置，不修改或下载系统浏览器。Python依赖统一在根 `requirements.txt`。可设 `browser_session: false` 关闭，或指定已安装的 `browser_channel: chrome`。

会话保存在 `cache/game/strategies/bilibili_browser/session.json`，24小时过期，Cookie值不进入报告或日志；这不是登录所用的旧 `cache/cookie`。页面要求人工验证码时保留现场和会话并返回受阻，不自动解验证码。该分支由正式程序自行运行，不需要 Agent 提前打开网页。2026-09-22 已实测独立headless获取结果、保存4枚Cookie、后续HTTP受阻时通过浏览器搜索回退，以及深域3-6来源详情核验成功。

实际来源和试验队伍只写忽略的 `cache/`，不提交真实攻略或账号信息。离线验证：

```powershell
./.venv/Scripts/python.exe -X utf8 -m unittest discover -s test -p test_abyss.py -v
```

2026-09-22 实测：红焰3-1～3-10通过，次数耗尽后自动切苍波；苍波1-10保存队伍存在未确认身份，未开战。218项离线回归通过。失败3次自动换属性已有离线覆盖，仍待自然实战状态验收。

重试先分析战斗采样：临近超时、连续无减员迹象且首领剩余生命超过25%时，换输出/破防阵容；减员且已接近击破时允许同队额外一次，其他情况优先调整。25%是可审查的保守启发式，不是游戏定律。候选由游戏属性筛选的已拥有头像与本地数据库技能描述生成，保留坦克和至少一名治疗；实际等级、Rank、星数、专武必须重新核验，明显低培养替补不拿来凑次数。候选耗尽提前停止，预算不要求用完，不随机拼满组合。此为本地试验，不宣称最优解或攻略复现。


## 用户优先来源与可选升星

每个需要攻略的任务在自己的配置段提供 `source_urls`，例如 `Abyss.source_urls` 和 `Dungeon.source_urls`；链接不跨任务共享。接受B站视频及攻略网页链接；获取元数据、正文不等于已解析成可执行队伍。B站同时采集UP主评论（热门第一页、置顶和返回的楼中楼）的文字、图片与链接，一层内最多补充8条引用，保留评论ID和父视频，不把普通观众留言标为UP说明。站点验证或评论失败单独记录，不丢失有效视频来源。

深域对已支持的战斗布局、简单五头像通用行和练度表进行多帧识别，并保留范围、SET及培养证据；完整覆盖、特殊轴、任意网页/评论图解析仍有待实现。实际培养试打需启用 `allow_local_trials`，缺失要求不会伪装成完整攻略复现。

`Abyss.allow_five_star_upgrade` 与 `Abyss.allow_divine_amulets` 均默认false，GUI标记危险操作。分别允许拟上场角色升至5星及碎片不足时用女神秘石兑换；消费记录进入运行报告。它们不授权六星、专武投入、购买体力或重置。已实测通过「★变更」免费将已解锁的3星切为5星。2026-09-23 静流（情人节）3→5星及两批女神秘石购买已实测：分别买111/150片、花555/750女神秘石，回执核对碎片与余额前后值；两次升星共消耗90,000玛那。单个0和无标签碎片图标需针对已知字段局部识别；未知回执保留现场，不能盲目重购。具体战斗结果见[深域实测](game-knowledge/abyss.md)。
